# 🚀 Release v2.1.0 - Spring 2026 Updates (March 2026)

**Version:** 2.1.0 | **Type:** Minor | **Date:** March 7, 2026

---

## ✨ What's New

### Dark Mode for Mobile Users

✨ **Full dark theme support across all screens**
- Toggle dark mode on in Settings > Appearance
- Now available for both iOS and Android users
- Easier on the eyes during evening use

### Fresh Onboarding Experience

✨ **Streamlined signup process - just 4 steps!**
- Progress indicator keeps you informed as you go
- Save your progress and resume later - no more starting over
- Email verification now happens in the background, so you can start using the app right away

### Webhook Integration for Developers

✨ **Real-time event notifications via webhooks**
- Configure webhook endpoints in Developer Settings
- Out-of-the-box integrations with GitHub and Slack
- Never miss an event - get notified instantly when things happen in your account

---

## 🐛 Bug Fixes

🐛 **Fixed modal overlay issues on dashboard**
- Modals now always appear on top of other elements
- No more clicking through hidden overlays

🐛 **Corrected API rate limiting calculations**
- Request counter now accurately reflects remaining quota
- Developers can trust the headers returned by our API

---

## ⚡ Improvements

⚡ **Faster, modern app with React 18**
- Improved performance across the entire platform
- New concurrent rendering features for smoother interactions

📚 **Help for v1 Users**
- Comprehensive migration guide now available
- Step-by-step instructions and complete list of breaking changes
- Making your upgrade journey as smooth as possible

This release includes new user-facing features (dark mode, improved onboarding, webhooks), bug fixes, performance improvements via React 18 upgrade, and documentation updates for migrating from v1.x. These changes warrant a **MINOR** version bump per semantic versioning guidelines.
