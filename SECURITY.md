# Security Policy

## Overview

This repository contains only documentation (Markdown files) for Claude Code skills. There are no executable programs, dependencies to install, or runtime requirements.

## Reporting Issues

If you discover any issues related to this repository:

- **Security vulnerabilities**: Please report via GitHub Issues with a description of the concern
- **General issues**: Use GitHub Issues for feature requests or documentation improvements

## What This Repo Contains

- Markdown documentation files (`.md`)
- YAML frontmatter for skill metadata
- No executable code
- No external dependencies to install
- No secrets, API keys, or sensitive data

## Best Practices

When using skills from this repository:

1. Always review the content before copying to `~/.claude/skills/`
2. Understand what each skill does before invoking it
3. Test in a safe environment first if concerned about behavior
